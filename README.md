A frontend-based web application that simulates and visualizes real-time crowd levels in public buses. The project focuses on clarity, usability, and live analytics without relying on hardware or backend services.

 Project Overview

Public transport users often face uncertainty about bus crowd conditions. This project addresses that gap by providing a real-time dashboard that displays passenger occupancy levels for different buses using simulated live data.

The goal is simple:
Show crowd levels clearly, instantly, and visually.

 Objectives

Visualize bus crowd levels in real time

Reduce uncertainty for passengers

Demonstrate smart transportation concepts

Build a clean, interactive frontend project

 Features

Real-time passenger data simulation

Occupancy percentage calculation

Crowd status indicators (Low / Medium / High)

Interactive charts and live counters

Multi-page flow (Landing → Dashboard)

Responsive and modern UI design

 System Workflow

Simulated passenger count is generated dynamically

Occupancy percentage is calculated

Crowd status is determined based on thresholds

Dashboard updates automatically at intervals

Charts and indicators reflect live changes
